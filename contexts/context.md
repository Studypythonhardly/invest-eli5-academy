# 项目核心上下文：零基础投资冒险学院（InvestELI5 Academy）

## 项目目标
构建一个面向完全零金融基础用户的**全链路交互式投资学习应用**，遵循 **ELI5（Explain Like I'm 5，5岁小孩也能听懂的大白话）** 教学法，帮助学习者从"完全不懂金融"循序渐进地成长为能够独立分析**股票市场走向、个股财报估值、公募基金、ETF、债券、黄金、宏观经济周期与资产配置**的理性投资者。

## 核心教学方法论（ELI5 三层渐进法）
1. **生活大白话（零术语入门）**：先用奶茶店、水果拼盘、借条、菜市场、水龙头等日常场景建立直觉。
2. **动手玩实验（互动沙盒）**：通过滑块、场景开关、动态图表即时观察因果关系，在做中学。
3. **正式金融桥梁（进阶落地）**：在理解直觉后再引入专业术语（PE、ROE、ETF 折溢价、美林时钟等），并剖析常见新手坑。
4. **全站点击即懂**：正文中的金融术语自动渲染为可点击的虚线高亮胶囊，随时弹出 ELI5 白话卡片，绝不强行灌输。

## 技术架构
- **零外部依赖、开箱即用**：纯现代 HTML5 + CSS3（自定义设计系统，支持浅色/深色模式与 A股红涨绿跌 / 国际绿涨红跌切换）+ 模块化 JavaScript + 自研轻量级高精度 SVG 图表引擎。
- **模块化源码 + 一键单文件打包**：
  - `src/engine/`：纯数学金融计算引擎与 10 年市场模拟引擎（支持 `node --test` 单元测试）
  - `src/data/`：60+ 词条 ELI5 词典、8 大篇章 24 节互动课程、随堂测验与实战决策清单
  - `src/charts/`：自研响应式 SVG 折线图、面积图、K线/多空图、饼图/环形图与美林时钟罗盘
  - `src/labs/`：7 个专项深度互动实验室 + 第 8 个毕业级「10年穿越牛熊实战沙盒」
  - `src/ui/`：应用主框架、学习地图、课程阅读器、术语弹窗、成长勋章与持久化存储
  - `scripts/build.mjs`：零依赖 Node 构建脚本，将源码编译打包为可直接双击浏览器打开的单文件 `index.html`（无 `file://` CORS 限制）
  - `scripts/serve.mjs`：内置本地 HTTP 开发服务器（`npm start`）
  - `tests/`：Node 原生自动化测试套件，覆盖所有金融公式、课程引用完整性、术语链接完整性与构建产物校验
