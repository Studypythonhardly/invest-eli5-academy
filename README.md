# 🧭 零基础投资冒险学院（InvestELI5 Academy）

用 **ELI5（5岁小孩也能听懂的大白话）** + **8 大实时交互金融实验室**，带你从完全没接触过金融的零基础小白，一步步成长为能够独立分析**股票市场走向、个股财报与估值、公募基金、ETF、债券、黄金、宏观经济周期与全天候资产配置**的理性投资者。

## 🚀 立即开始（两种零门槛打开方式）

1. **最简单方式（双击即用）**：直接用任意现代浏览器（Chrome / Edge / Safari / Firefox）双击打开项目根目录的 `index.html` 即可开始学习，**100% 离线可用，无需安装任何依赖**！
2. **本地服务器预览**：
   ```bash
   npm start
   # 然后在浏览器访问 http://127.0.0.1:3000
   ```

## ✨ 核心教学特色（拒绝强行灌输术语）

- **三层渐进式 ELI5 教学法**：每节课先讲一个生活大白话故事（开奶茶店、买水果拼盘、拔河比赛、央行水龙头）→ 再通过互动模拟器动手调参验证 → 最后才无缝衔接正式金融概念与新手避坑指南。
- **全站术语点击即懂**：正文里所有带虚线下划线的金融名词（共 **56+ 条高频术语**），点一下立刻弹出 ELI5 白话卡片（一句话解释 + 生活比喻 + 实战提醒），绝不卡壳。
- **贴心细节**：顶部支持一键切换 **A 股习惯（红涨绿跌）** 与 **国际/美股习惯（绿涨红跌）**，支持浅色纸张与深色护眼主题，所有学习进度与经验值自动保存在浏览器本地。
